# Dashboard screens for the MVP

Type: grilling
Status: resolved
Map: ../map.md

## Question

What screens does the MVP dashboard have, who can log in and with what roles, and is live call monitoring in scope?

## Answer

Settled with the owner 2026-10-03.

**Seven screens**
1. **Home:** today's calls, connected, booked and cost, plus live call status.
2. **Leads:** list, filters, Excel import, and a detail page per Lead (Submissions, Call Attempts with transcript and recording player, event log, manual actions).
3. **Calls:** log of every Call Attempt.
4. **Campaigns:** backlog batches with start/pause and soft-launch gates.
5. **Discovery Calls:** with Attended / No-show / Won / Lost buttons.
6. **Settings:** operational config with change history.
7. **Quality:** judge-flagged calls and the labelling queue.

**Access**
- **Sign in with Google** (hoplonco.com Workspace accounts).
- **Admin only, no roles/RBAC in v1** (owner: keep it simple).

**Live listening**
- Not in v1; live status only.
